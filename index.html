Mark Web — Marcador de Texto

Última atualização: 20 de agosto de 2026 · ID: hoioajkkjjlkbcidgdlicfmcblominpk

Esta política descreve como a extensão Mark Web — Marcador de Texto trata as informações do usuário. A extensão foi criada para permitir que você marque e destaque trechos de texto em páginas da web.

Resumo: a Mark Web não coleta, não transmite e não vende nenhum dado pessoal. Tudo o que você marca fica salvo apenas no seu próprio navegador.

01 Dados que a extensão coleta

A Mark Web não coleta dados pessoais identificáveis. Especificamente, a extensão não coleta:

  • nome, e-mail, endereço ou dados de contato;
  • dados de saúde, financeiros ou de autenticação (senhas, cookies de sessão);
  • histórico de navegação enviado a servidores;
  • localização, dados de identificação pessoal ou comunicações pessoais.

02 Dados armazenados localmente

Para funcionar, a extensão guarda no seu navegador as marcações que você mesmo cria: o texto destacado, a cor escolhida e o endereço (URL) da página onde a marcação foi feita.

Essas informações são gravadas exclusivamente no armazenamento local do Chrome, no seu dispositivo. Elas não são enviadas para nenhum servidor, nem para o desenvolvedor, nem para terceiros.

03 Compartilhamento de dados

Não há compartilhamento, venda, aluguel ou transferência de dados do usuário para terceiros, sob nenhuma circunstância. A extensão também não utiliza serviços de análise, publicidade ou rastreamento.

04 Permissões solicitadas

As permissões pedidas pela extensão são usadas apenas para a sua finalidade declarada:

  • storage — salvar suas marcações localmente para que continuem visíveis ao recarregar a página;
  • activeTab / scripting — aplicar o destaque no texto da aba que você está usando no momento, apenas quando você aciona a extensão.

05 Controle e exclusão

Você pode remover suas marcações a qualquer momento pela própria interface da extensão. Ao desinstalar a Mark Web, todos os dados armazenados localmente são apagados junto com ela.

06 Alterações nesta política

Se esta política for atualizada, a nova versão será publicada nesta mesma página, com a data de atualização revisada no topo.

English version

Mark Web — Text Highlighter does not collect, transmit, or sell any personal or sensitive user data.

The extension stores only the highlights you create — the selected text, the chosen color, and the URL of the page — using Chrome's local storage on your own device. This data never leaves your browser and is never sent to the developer or to any third party.

  • storage — keeps your highlights available when you revisit a page.
  • activeTab / scripting — applies highlights to the tab you are currently viewing, only when you activate the extension.

No analytics, advertising, or tracking services are used. You can delete your highlights at any time from the extension, and uninstalling it removes all locally stored data. Questions: alapedrodev@gmail.com.
